# aqua-registry-g2

The next generation of [aqua-registry](https://github.com/aquaproj/aqua-registry).

A registry aqua reads as JSON rather than as YAML it has to evaluate. Each package has
a branch of its own, `pkg_<encoded name>`, holding the definition it is generated from
and the result for every version:

```
pkg_suzuki-shunsuke_ghalint
├── registry.yaml                     the definition, written once
└── versions/
    ├── v1.5.5/registry.json          what aqua reads
    └── v1.5.6/registry.json
```

`main` holds no package. It carries the template a package branch starts from,
`index.json` for the package list, and the workflows that keep the rest in step.

The definitions are generated by [ar2](https://github.com/aquaproj/ar2) and arrive as
pull requests, which merge when their checks pass. What a version resolves to is
therefore decided once, when it is generated, rather than every time somebody installs
it.
